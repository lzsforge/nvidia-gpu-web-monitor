# 系统 GPU & CPU 监控系统 (System GPU & CPU Monitor)

这是一个专为本地和局域网打造的**高保真、跨平台、极具现代科技美感**的硬件监控与风扇控制面板。它能够让您直观地实时掌控显卡与处理器的各项关键数据，并提供安全、可靠的手动风扇转速调节功能。

## 🌟 核心特性

- **双模自适应美学设计**：
  - **夜晚模式**：极具科技感的**魅影紫与极光青**霓虹发光主题，搭配半透明的深蓝宝石毛玻璃卡片（Backdrop Blur）。
  - **白天模式**：清爽素雅的**深邃靛蓝与静谧绿**霜白玻璃卡片，专为白昼及明亮环境办公设计。
  - **自动跟随系统**：无缝读取操作系统的深浅色设置，实现 `0.35s` 极其顺滑的无感过渡。
- **高阶动画交互**：
  - **风扇动态物理拟真**：风扇 icon 的**旋转动画速度会跟随硬件当前的实际风扇转速百分比进行动态拟真旋转**（转速越高，转速动画越快；停止时自动静止）。
  - **Neumorphic 微光滑块**：完全重新定制的滑动调节杆，带有呼吸灯色彩填充与物理悬浮质感。
  - **滑入式 Toast 弹窗通知**：使用非阻塞、优雅的动态 Toast 消息提示，彻底代替了生硬的系统 `alert()` 弹框。
- **全方位硬件监控**：
  - **GPU (NVIDIA)**：实时监控显卡型号、核心温度、显卡/显存利用率、显存分配占用、功耗/功耗上限限制、图形/显存核心频率、风扇转速百分比等。
  - **CPU & 操作系统**：物理核心数、逻辑线程数、总体温度与负载利用率、物理内存占用、每颗核心当前频率、系统传感器温度列表、风扇实际 RPM 转速等。
- **风扇手动精准控制**：
  - 支持将 GPU 和主板 CPU 风扇（通过 PWM）的转速设定在 20%~100% 的任意区间。
  - 提供一键“恢复自动”按钮，安全地将硬件控制权交还给 NVIDIA 驱动或主板。
- **基于 Auth Key 的轻量级安全认证**：
  - 自动生成 32 位随机安全密钥，保障您的局域网硬件调测安全。

## ⚙️ 环境依赖与配置 (极重要)

### 1. 显卡依赖 (GPU Monitor)
本程序通过官方 NVML (NVIDIA Management Library) API 读取状态。请确保您的系统：
- 已安装 NVIDIA 显卡驱动。
- 在 Linux 系统上，部分显卡（如 Max-Q 笔记本卡）或由于系统没有开启 Xorg 控制权，可能不支持手动风扇写入。Linux 修改风扇通常需要 **root 权限**（运行 `sudo`）。

### 2. 主板与处理器传感器依赖 (CPU Fan Control)
在 Linux (如 Ubuntu/Debian) 系统中，为了让后端程序能正确识别主板温度传感器和 PWM 风扇控制接口，您**必须**安装 `lm-sensors` 包，并运行它的探测工具让系统尝试识别并加载主板的传感器驱动：

```bash
# 1. 安装传感器识别包
sudo apt install lm-sensors

# 2. 自动检测并匹配传感器驱动
sudo sensors-detect
# 一路按回车 (Enter) 采用默认选项探测传感器
# 在最后会询问是否将检测到的模块写入 /etc/modules 以便开机自启，请输入 YES 写入加载新驱动
```

为了**让刚检测到的驱动立即生效而不用重启电脑**，请在终端中依次运行以下命令加载对应的内核模块：
```bash
sudo modprobe coretemp
sudo modprobe nct6775
```
*(注意：`nct6775` 对应绝大多数标准消费级台式机主板芯片，如果您的主板使用的是其他传感器芯片，请在第 2 步的 `sensors-detect` 输出报告的末尾查看它推荐的 `modprobe` 模块名称并进行加载。)*

如果探测成功并加载了对应驱动，重新启动我们的监控程序后，CPU 监控卡片下的**选择控制设备**下拉菜单里就会正常出现可用的 PWM 硬件风扇了！

## 🚀 安装与运行

### 选项 A：使用 `uv` 极速运行（推荐）

`uv` 是目前最快的 Python 依赖与虚拟环境管理工具：

1. **初始化虚拟环境并安装依赖**
   ```bash
   uv venv
   source .venv/bin/activate  # Windows 下运行: .venv\Scripts\activate
   uv pip install fastapi uvicorn nvidia-ml-py pydantic psutil
   ```
2. **运行服务**
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

### 选项 B：使用标准 `pip`

```bash
# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate  # Windows 下运行: .venv\Scripts\activate

# 安装依赖
pip install fastapi uvicorn nvidia-ml-py pydantic psutil

# 启动程序
python main.py
```

## 🔑 认证与首次登录 (Auth Key)

1. **首次运行**程序时，后端会在项目根目录下自动创建一个 `config.json`，并写入一个高强度的 32 位随机字符作为 `auth_key`。
2. 启动控制台会同步打印出**一键登录免密链接**，如：
   `http://localhost:8000/?key=8c78c...df61a`
3. 复制该链接在浏览器中打开，前端会自动安全保存该密钥。此后您直接访问 `http://localhost:8000/` 即可直接进入 Dashboard 仪表盘。
4. 如果您更换了浏览器或清理了本地缓存，只需在全新设计的毛玻璃登录框中重新输入或粘贴该密钥即可。

## ⚠️ 安全注意事项
- 当您通过手动滑动条设定了显卡或 CPU 的转速后，硬件风扇将保持在**固定转速**上，此时风扇转速**不会**再随着温度升高而自动提高！
- 请在进行高强度计算/游戏/炼丹时**密切关注硬件温度**，以免过热损坏。当调测结束后，请务必点击**“恢复自动”**按钮，将控制权安全归还给驱动。
